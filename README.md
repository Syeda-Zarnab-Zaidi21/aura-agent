# 🤖 AURA — Autonomous Task & Workflow Agent

> An evolving Python-based personal task and workflow assistant, progressively developed into an autonomous AI agent.

## 📌 About AURA

AURA is a learning-driven AI agent project designed to evolve from a Python CLI application into an autonomous task and workflow assistant.

The project is intentionally developed in stages. Each stage applies concepts learned during my Python and AI engineering journey.

The goal is not only to build AURA, but to document how it evolves from fundamental programming concepts into an AI-powered agentic system.

---

## 🚀 Current Version

### v0.1 — Authentication

AURA currently provides a basic command-line authentication system.

### Implemented

- CLI menu
- User Sign Up
- User Sign In
- Username validation
- Password confirmation
- User data stored in a Python dictionary

### Python Concepts Applied

- Variables
- Input / Output
- Conditional statements
- while loops
- Lists
- Dictionaries
- Comparison operators
